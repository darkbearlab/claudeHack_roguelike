# 局外進展:說故事,不強化

> 這份文件記錄的是**設計討論的結論和理由**,不是已完成的功能。目前實作到的只有
> 篝火旁的火防女和對話系統,其餘是規劃。每一條「為什麼」都值得留著,因為後來要做的
> 時候,忘掉理由就會做成另一個東西。

## 立場

**局外進展不給任何數值。** 不是不能,是不要。

這個專案從第一次討論就排除了「腦內啡式」的成長,而後來所有的平衡工作——量出來的
耐力經濟、承諾的定價、十二把武器的死亡數——都建立在「玩家的能力來自裝備和判斷」
這個前提上。一個給數值的局外系統會從外面把那些數字全部弄髒,而且是**不可測的**弄髒:
同一個 build 在第一場和第二十場不是同一個東西。

所以局外留下來的東西只有一種:**你知道的事**。

## 形狀

有些種子的篝火旁坐著人。他們說破碎的故事,給你一片收藏品。收藏品在通關後留下。
收集夠了,玩家能從碎片裡拼出一個**種子短語**,打進標題畫面的種子框,那裡有真結局。

## 為什麼這個點子在這個遊戲特別成立

**一、種子在這裡是真的東西,不是比喻。**
`seed#depth` 決定每一層長什麼樣,而種子是人類可讀的短語(`makeSeedPhrase`)。所以
「拼出藏有真結局的種子」不是敘事裝置——玩家真的會把那幾個字**打進輸入框**。多數
遊戲要做這種事得假裝一個介面出來;這裡它是原生的,而且玩家整場遊戲都在用它。

**二、它碰不到平衡。** 見〈立場〉。

**三、篝火房已經是聖域。**
「篝火房不生怪」那條規則本來是為了死後重生不被埋伏,結果剛好替 NPC 鋪好了位子:
她可以坐在火邊,而我們**已經**保證那裡不會有東西衝上來打斷對話。

## 「真結局的種子」其實是一個過關密碼

這是討論裡最重要的一次修正。

那串字**不需要真的生成一個地牢**。它是一個密碼,像《Doki Doki Literature Club》
刪掉莫妮卡的檔案——沒有真的刪掉什麼,那是一種互動方法。

這樣更好,理由有三:

1. **種子框本來就是「你要去哪裡」的介面。** DDLC 的力量來自「玩家早就懂的介面被
   拿來做一件意料之外的事」。這裡完全一樣:那個框一直是通往某處的門,只是這次你
   知道要去哪。不需要教學,不需要解釋。
2. **結局不必受 mapgen 約束。** 檢查發生在按下「走下去」的瞬間,之後完全自由。
3. **密碼可以是任何東西**——但**必須看起來像種子短語**,見下。

### DDLC 真正的教訓不是「那是假的」

而是:**假的那件事有真的後果。** 刪掉莫妮卡之後她真的不在了,遊戲真的變了。如果
只是播一段影片然後一切照舊,那個手勢就會退化成一個按鈕。

所以:**打下真結局的種子之後,遊戲要永久地不一樣。** 不是變強,是變了——之後每一
場都有某個東西不同。技術上只是 localStorage 一個旗標,便宜到不行,但它讓那次輸入
變成**你做了的事**,而不是你看了的東西。

這條做到了,「其實只是密碼」就不會傷到它——正如知道莫妮卡的檔案沒被真的刪掉,也
不會讓那個瞬間變便宜。

### 幻覺要維持到哪一刻

真種子那一場**必須像一場 run 那樣開始**:打字、按走下去、第一層載入、你站在篝火
旁——**然後**才有東西不對。一按下去就跳結局畫面,種子框就從門變回按鈕了。

而且密碼要長得像種子(`ember-wyn-thas` 那種形狀)。碎片拼起來要是一句「看起來可以
打進種子框」的東西——那個「看起來可以」就是誘餌,也是讓玩家**自己想到**要去試的
關鍵。**沒有人告訴他,他自己猜的。** 那是 DDLC 最好的部分。

## 時間編織者:種子和碎片的管理者

她站在灰燼之廳的階梯旁,而且**她就是門**。走到階梯上不會發生任何事,只會被告訴
「階梯是編織者的」——一趟旅程是從跟她說話開始的,不是從踩上去開始的。

階梯**還是畫出來的**,這是刻意的:一個唯一的出口是「一個你還沒跟他說過話的人」的房間,
讀起來像一個沒有出口的房間。階梯是提示,她是門。

她也**不站在階梯上**。火防女第一次被放置的時候被塞進房間裡「鄰居最少」的那一格——
而那正好是門口——她就變成了一個塞子。**一個你非跟他說話不可的人,是最不該放在通道上的
東西。**

### 一個人,三個年齡

咖啡色皮膚、琥珀色眼睛、同一條鏽紅頭巾和藍綠披肩。變的只有看起來幾歲,以及她說的話:

| | |
| --- | --- |
| 老婦 | 「有些線斷在半路。斷了也是一種形狀。」 |
| 女孩 | 「你死掉的時候我有在看。不要怕,我會把線接回去。」 |
| 成年女子 | 「同一條線,你走第幾次了?我沒有在數。你有。」 |

**是資料不是三個 NPC**,因為她是同一個人。年齡在**進入廳堂時抽一次**,所以你站在她
面前的時候她是固定的,下次回來才會不一樣——那要讀起來像「她不固定在時間裡」,不是像
閃爍。任何要讀她的臉或台詞的東西都得經過 `weaverAt()`,所以只有一個地方知道一個 NPC
可以有不只一張臉。

**抽籤用的是丟棄式的 RNG,刻意不是 `this.rng`。** 種子決定地城,從那裡面拿一個數字會
把後面每一個生成決策整個位移——那正是 DESIGN.md 裡 `placeKeeper` 那條記過的錯。這件事
有測試守著:同一個種子進廳堂十二次,看過她的多個年齡,而第一層必須是同一座。

## 已知的四個坑

**一、抽獎問題。** 「有些種子會碰到 NPC」——用隨機種子的玩家可能永遠碰不到,碰到
也可能一直重複同一片。用 `hash(seed) mod N` 決定碎片,五次通關拿到重複的機率不低;
「跳過已有的」又會破壞決定論(同一個種子不同結果)。

> **解法:足跡。** **每個種子的火邊都有人**——這是定案,不是「有些種子才有」。她是
> 一個**鉤子**:那個位置永遠被佔著,所以每個玩家都會遇到,不靠運氣,也不需要任何
> 「這個種子有沒有中」的判斷。
>
> 種子之間的差異**表現成「來的是誰、他說什麼」**,而不是「有沒有人」。空著的火邊
> 只是一個沒有東西的房間;坐著一個不認識的人,才是一條線索。
> 每個 NPC 給一片碎片,**同時說出下一片所在的種子**。碎片的取得是線性的,沒有抽獎
> 也沒有重複;但真結局的種子**不是**最後一個 NPC 直接給的,它散在碎片的文字裡,
> 要玩家自己拼。謎題保留,路上不迷路。

**二、原始碼是公開的。** Repo 就是網站,密碼一定會被挖出來。存雜湊而不是明文,把
門檻從「順手」提到「故意」——但真正的答案是下一條。

> **沒收集碎片、直接打密碼的人會怎樣?** 傾向:**密碼只是門的位置,碎片才是鑰匙。**
> 沒有碎片的人到了那裡,那個地方是空的,或者那個人不認得你。這不是防劇透(防不了),
> 是讓知道門在哪跟能打開門變成兩件事。而且它呼應 DDLC:在錯的時間刪檔,得到的
> 是不一樣的東西。

**三、存檔在 localStorage,是每個瀏覽器一份。** 手機收的碎片桌機看不到。需要匯出/
匯入——而它剛好可以長得像一個種子短語,美學上一致。

**四、碎片放哪裡。** 背包是裝備和消耗品的地方,現在已經三十筆;一個沒有任何機制
效果的東西放進去會很怪。碎片需要自己的畫面。

## 其他決定

- **碎片先是 unbanked 的。** 走「死掉會掉在原地、要帶回篝火才算數」那條現成的路:
  NPC 給你之後你得**活著帶到底**才會進入永久收藏。這樣「通關後留下」不是結算畫面
  的一條規則,是你**背著它走完十層**的過程。魂系那種「我拿到了,現在得帶出去」的
  張力,免費得到。
- **收藏畫面只放文字,不放進度條。** 「5/7」會把它變成清單。魂系的力量在於你
  **不知道自己漏了多少**。
- **有時候 NPC 已經死了。** 屍體系統是現成的:某個種子你走到火邊,那個人不在了,
  碎片在他的屍體上,他來不及說的話你只拿到一半。零新機制。
- **整條線完全可跳過。** NPC 不擋主線,不知道它存在的人也能通關。
- **碎片不能有任何數值效果。** 哪怕只是 +1 血,都會把它變成另一個成長系統。
- **真結局不能只是換一段結尾文字。**

## 還沒決定的

**「之後每一場都不一樣」是失去還是留下?**
失去(那個人不在火邊了、某句話沒有了)比較魂、比較安靜;留下(火邊多了一樣東西、
開場多一句話)比較溫柔。這決定整個結局的溫度。

> 部分定案:**不會用「火邊空掉」來表現。** 見上面的鉤子——那個位置永遠有人,
> 變化表現在**換一個人、換一段話**。

**足跡要多長?** 一場 run 半小時到一小時。五片碎片 = 五次通關 + 真種子那一場,
大約五到六小時的 meta。

**底下燒著的是什麼?** 現有文字已經埋了東西:「十層之下,有什麼東西還在燒」、
First Flame、篝火、所有名字都是灰燼系的(Ash、Cin、Ember)。骨架在那裡了。

## 現在實作到哪

篝火旁坐著**火防女**。走向她會說話,她目前說的是這一場的統計數字——那是
placeholder,佔住對話系統的位子,好讓上面那些東西之後有地方長出來。

實作上有三件事值得記下來:

**她打不到,而且那不是一個旗標說的。** 她住在 `level.npcs`,而遊戲裡每一次攻擊都
是透過 `level.enemyAt` 結算的——所以她對**所有**攻擊同時免疫,不需要任何一個地方
寫特例。`invulnerable: true` 這種寫法只能保證到「每個未來的攻擊都記得檢查」為止。

**她站哪裡是個真問題。** 她不能被殺、不能被推開,所以對尋路來說是一面牆,而且是
每層自動放置、就在所有人降落的路線旁邊的牆。兩個猜錯的版本都是實測抓到的,見
DESIGN.md 的〈猜錯的啟發法〉和〈在生成流程裡抽一個亂數〉。現在的規則:**篝火外圈
第二圈、最開闊的那一格**,而且**完全不碰亂數**。

**走進她是對話,不推進回合。** 她站在一個不生怪的房間裡,而為了一段在安全的地方
進行的對話收一個回合,只會教人不要去講話。

**立繪跟地圖上的圖是兩張。** 地圖上那張是正上方俯視——那是一個形狀,不是一張臉,
縮進對話框只會看到兜帽的頂端。立繪用同一條管線的 `portrait` kind(正面平視)。
